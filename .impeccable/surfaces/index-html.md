# Surface: index.html (portfolio home)

Scope: the whole single-page portfolio. Visitor mode: Experience (the apps and projects lead; the interface recedes).

Audience and job: a visitor arriving from an App Store page, GitHub repo, TestFlight link or post, on iPhone or Mac, asking "who made this and what else did they build?" Action: open an app or repo in one tap. Proof: real icons, real platform availability, real links, public source. Constraints: static HTML/CSS, no invented claims, self-hosted or system fonts only, AA contrast, 11px floor, no JS required.

Unresolved: none pinned by the user; direction delegated. Portrait may return later if the user wants it.

## Direction contract

THESIS: The portfolio is a developer documentation page for the developer himself. It refuses the slogan-hero-plus-colored-bento arrangement; every app is a documented symbol with Availability, Overview and See Also.

OWN-WORLD: White paper, near-black ink, one blue link color, 1px hairlines and a hairline sidebar. One system sans in two weights. Availability rows with platform-name badges. Declaration blocks in a grey well set in mono. No cards, no pills, no italic display, no eyebrows.

STORY: "This is a real body of native work, precisely described." Visitor scans the sidebar, opens the app they came for.

FIRST VIEWPORT: Left: sticky 260px navigator (Apps, Projects, About) with hairline. Right: breadcrumb, H1 "Joao Valente", a one-line abstract, Availability badges (iOS, iPadOS, macOS, Open source) in the documentation order title/abstract/availability, the page Declaration well, then the first app symbol (RedSum) begins within 900px: icon 72px, name, @available declaration, overview paragraph, See Also links row. Primary action = the app's App Store link, first link in each block.

FORM: Apple developer documentation page grammar; my top-ranked grounded candidate, chosen as IMPECCABLE'S PICK; seed key 1bf17aa3.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
